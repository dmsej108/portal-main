# 프로젝트 구조 가이드

이 문서는 `portal-admin` 프로젝트의 주요 폴더와 역할을 정리합니다.

## 최상위 폴더

- `app/`
  - Next.js 앱 루트입니다.
  - 페이지, 레이아웃, 라우트별 컴포넌트를 포함합니다.
  - 현재 다음과 같은 하위 경로가 있습니다:
    - `app/marketing/`
    - `app/sub/`
    - `app/system/`

- `components/`
  - 재사용 가능한 UI 컴포넌트 모음입니다.
  - 현재 다음 하위 폴더가 있습니다:
    - `components/layout/` : 레이아웃 관련 컴포넌트
    - `components/ui/` : 공통 UI 컴포넌트

- `lib/`
  - 라이브러리 코드, 설정, 헬퍼를 모아둔 폴더입니다.
  - 현재 다음 하위 폴더가 있습니다:
    - `lib/config/` : AG Grid, React DatePicker 등 컴포넌트 설정
    - `lib/validate/` : 유효성 검사 관련 코드

- `public/`
  - 정적 자산을 보관하는 폴더입니다.
  - 이미지, 폰트, favicon 등 변경 가능한 정적 리소스를 둡니다.
  - 현재 `public/image/` 하위 폴더가 있습니다.

- `styles/`
  - 전역 CSS와 컴포넌트 스타일 파일이 위치합니다.
  - 현재 다음 하위 폴더가 있습니다:
    - `styles/base/` : 공통, 레이아웃, 리셋 등 기본 스타일
    - `styles/compont/` : 버튼, 폼, 테이블 등 컴포넌트 스타일

- `docs/`
  - 프로젝트 문서용 폴더입니다.
  - 현재 `DEPENDENCIES.md`, `STRUCTURE.md` 파일이 포함됩니다.

- `package.json`
  - 프로젝트 의존성, 스크립트, 메타데이터를 정의합니다.

- `next.config.ts`
  - Next.js 설정 파일입니다.

- `tsconfig.json`
  - TypeScript 컴파일 및 경로 설정입니다.

## 주요 폴더 설명

### `app/`
Next.js의 앱 디렉터리 구조를 따릅니다. 각 폴더는 URL 라우트에 대응하며, `page.tsx` 파일은 해당 경로의 페이지를 렌더링합니다.

- `app/marketing/` : 마케팅 관련 페이지 (이벤트 등)
- `app/sub/` : 서브 관련 페이지
- `app/system/` : 시스템 관리 페이지

### `components/layout/`
공통 레이아웃 컴포넌트를 포함합니다. 예를 들어 헤더, 내비게이션, 페이지 컨테이너 등이 들어갑니다.

### `components/ui/`
입력 폼, 검색창, 페이징, 날짜 선택기 등 재사용 가능한 UI 컴포넌트를 저장합니다.

### `lib/config/`
외부 라이브러리 구성과 공통 설정을 모아 둡니다.

### `lib/validate/`
폼 검증 스키마 또는 검증 로직을 관리합니다.

### `styles/`
CSS 파일이 모여 있는 공간입니다. 전역 스타일과 컴포넌트별 스타일을 분리하여 구성합니다.

## 사용 방식 제안

- 새 문서는 `docs/`에 추가하세요.
- 새로운 재사용 컴포넌트는 `components/` 아래에 기능별로 분류합니다.
- 페이지 단위 코드는 `app/` 안에 유지합니다.
- 앱 공통 설정은 `lib/` 아래에 둡니다.
